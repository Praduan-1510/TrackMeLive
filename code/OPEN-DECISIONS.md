# Open decisions

Engineering questions left open on purpose, with what settles each one. FSD-level decisions are in the FSD, marked "(decided …; confirm)".

| Raised | Question | Current state | Decide when |
| --- | --- | --- | --- |
| Oct 18 (Sprint 2, Android-Core) | How the Kotlin schema generator types enums whose wire value is a number or mixed (`stop_minutes` is 15/30/60; `default_stop` is "call" or a number). The generated data classes type them as Kotlin enums, so Firestore's `toObject(ShareSession::class.java)` would fail on a timer session. Today nothing uses `toObject` for these (Android parses session docs by hand; Swift's `Int`-backed `Codable` enums decode fine). Likely fix: the data class field takes the wire type (`Long?` / `Any?`) and an `@get:Exclude` accessor returns the enum, plus a JVM test through Firestore's mapper. | Generated as enums; Android reads by hand | Start of Sprint 3, before anything calls `toObject` on these types. |
| Oct 18 (Sprint 2, iOS-Core) | FCM device addressing on iOS. firebase-ios-sdk 12.19.2 deprecates `Messaging.token(completion:)` (the registration token) in favor of installation-ID registration (`register(completion:)`). The backend sends to `devices.push_token` (the registration token, x-decisions Q-ALERT-PUSH), so moving means Backend-Alerts sends by installation ID too. Today it's one deprecation warning in `ios/Firebase/FirebasePushTokens.swift`. | Registration token on both platforms | Before launch, or sooner if Firebase announces a removal date. Change the iOS app and the backend sender together. |
| Oct 19 (Sprint 2, owner) | Map provider and "Where Alex is" street names. Google Maps Platform needs billing on the Cloud project, which the owner won't take on. | **Decided Oct 19 (owner):** no Google. Android and the viewer draw OpenStreetMap data with MapLibre and OpenFreeMap's free vector tiles (no key, no account; donation-run with no uptime promise, so the style URL is one setting and the apps fall back to the keyless map when tiles don't load). iOS keeps MapKit (free). The street name comes from the sharer's phone (Android `Geocoder`, iOS `CLGeocoder`, both free) and travels on the session, area only while Approximate; the viewer stops calling any geocoder. | Done; the row stays as the record. |
| Oct 18 (Sprint 2, Viewer) | Referrer-Policy on the viewer's `/s/**` pages: `no-referrer` (today, in `backend/firebase.json`) or `strict-origin`. Browser keys restricted by HTTP referrer (Maps JavaScript, Firebase web) don't work under `no-referrer`. `strict-origin` sends only the origin, so the link token in the path stays private either way. | **Decided Oct 18:** `strict-origin`, in `viewer/index.html` and `backend/firebase.json`, when the first Maps key arrived. The link token stays out of every Referer, and the web key can be restricted by website. | Done; the row stays as the record. |
